# SpendWise – Personal Finance Tracker

SpendWise is a personal finance tracker designed to help you manage your money effectively. Database integration is straightforward, and data visualization provides a clear overview of your financial health.

## Key Features

### The 5 Screens

*   **Dashboard (Home):** Total balance, recent transactions list, and a summary breakdown.
*   **Transaction Details:** Individual breakdown of a selected expense.
*   **Add/Edit Expense (Create/Update):** Form with amount, category dropdown, date picker, and notes.
*   **Category Manager (Read/Delete):** View and manage custom categories (e.g., Food, Transport, Rent).
*   **Analytics/Profile:** Monthly breakdown charts and user settings.

### CRUD Operations

*   **Create:** Add new expenses and categories.
*   **Read:** View transaction history and category summaries.
*   **Update:** Edit existing entries to correct mistakes or update information.
*   **Delete:** Remove mistaken logs or unused categories.
